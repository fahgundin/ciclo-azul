# Decisões de Arquitetura (ADRs)

Registros curtos e datados das decisões técnicas do Ciclo Azul. Cada ADR descreve
o contexto, a decisão e as consequências. ADRs são imutáveis: se uma decisão mudar,
cria-se um novo ADR que supersede o anterior.
